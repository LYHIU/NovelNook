# 页间 UI 与阅读管理改版

本轮按用户“自由发挥、直接修改、提供预览”授权实施。保留书架、添加、设置的原有导航，以及详情中的文案、阅读状态、总览和笔记顺序。

| 刚开始看 / 状态颜色 | 新增“刚开始看”；七种状态分别着色，保留文字和选中标识；服务端 AI 输入契约同步 |

## 限制与后续

- 番茄官网搜索本机实测触发验证，未绕过验证；搜索不可用不是“没有匹配作品”。
- OCR 为候选识别，不保证每个字准确；尚未拿到用户报错时的原始截图。
- 长佩作者名检索打开官方个人主页；作品详情中的作者作品列表展示官网当前页，不声称已获取全部作品。
- 密钥“已配置”只表示已保存，不代表密钥有效或账户有余额；本轮未调用真实付费 AI 请求。
- 未连接 Android 真机，未生成新版 APK；本轮交付为源码、构建通过的页面包和预览图。真机 WebView、文件选择器和分享面板仍需设备验证。
- 仓库在本轮开始前有未提交的 Android/预览实现。提交时单独保留相关已有代码基线，再提交本轮改动；不纳入无关的规格文档改动。

## 界面文案约定

- 按用户要求，界面不使用口号、装饰性副标题或解释设计意图的段落。优先用准确的按钮名、字段名和状态表达操作；确有必要的错误、识别质量和配置反馈保留。
- 清理应用名下口号、平台宣传小字、截图入口与导入操作旁重复说明、空页面抒情文案和开发预览说明。截图入口统一“截图识别”，识别页以字段标签替代长段引导。
- 浏览器验证找书、截图确认正常及低置信度分支、空书架和设置状态；脚本语法与移动端构建通过。

## 控件优先的页面结构

- 用户进一步明确：已有导航与控件能表达页面用途时，不展示“我的书架”“找一本书”等重复页面标题，也不用文字解释界面意图。
- 两页标题块移除。书架以“搜索书架”输入框和“找书”按钮组成首行工具栏，之后直接展示筛选、排序和书籍；找书页直接展示平台与搜索控件。
- 仅调整 app.js 的两页结构与 style.css 的工具栏样式。浏览器验证搜索高亮、清空、找书跳转、平台切换，375 / 390 / 844px 操作栏同排且无溢出；语法检查与移动端构建通过。

## 液态玻璃参考图精修

用户提供了通透玻璃控件、雨窗背景聊天界面以及材质动效三张参考图，希望玻璃感更明显。第一版的白色填充和浅背景压低了透色与折射的可见度；本次保持主题二选一和操作布局，集中调整玻璃材质与交互反馈。

- `glass-wallpaper.svg`：新增项目内的抽象绿蓝光带背景，让控件有可见的环境染色。采用矢量渐变和柔化曲线，无外部图片或依赖。
- `theme.css`：降低白色填充，增加曲面反光与内外阴影；前三张书籍卡片和导航使用背景折射、表面染色、边缘高光分层，避免折射层重复采样自身描边。加强小字和筛选文字对比度，保留状态颜色的含义。增加导航胶囊滑动和局部高光响应，延续减少动效、增强对比度与减少透明度适配。
- `theme.js`：创建仅在玻璃主题显示的导航胶囊；监听现有导航选中状态和尺寸变化，保持胶囊对齐；通过按需的一次动画帧更新局部指针高光，无持续后台动画。切回绿色或开启减少动态效果时清理高光。
- `index.html`：导航位移强度从 -16 调整到 -26，增加卡片位移图（350×166、半径 22、边缘厚度 9、强度 -20）。仍采用已有技能的 SDF 生成器。

验证：320/375/390/768/844 宽度的书架、找书、设置无横向溢出；导航胶囊最终位置与按钮误差在 1.5 px 内。指针事件改变高光位置，离开后清理；搜索、平台切换、详情字数、主题保存恢复、减少动态效果和增强对比度回退通过，书籍存储前后完全相同。绿色主题和原样式书架截图逐像素一致。最终分层检查确认折射在底层、染色层未被旧边缘遮罩裁切，已修复迭代中发现的描边重影。移动端资源构建和 JavaScript 语法检查通过；尚未验证 Android 真机的 GPU 表现。

交付：`output/playwright/yejian-glass-v2-preview.html` 包含四页截图和动态演示；`yejian-glass-v2-motion.webm` 录制了高光移动、滚动透色、导航滑动及主题切换。第一版玻璃预览和已认可的绿色冻结基线均保留。


## 降低玻璃主题背景浓度

用户反馈背景颜色太重。仅在矢量背景上叠加 62% 的浅灰白色，降低绿蓝色饱和度与光带对比，并将背景加载前的底色改为浅灰绿；玻璃材质、边缘高光、动效与布局保持不变。同步更新四页截图和动态预览，构建移动端资源。
