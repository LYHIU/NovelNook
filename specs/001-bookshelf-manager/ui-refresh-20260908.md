# 页间 UI 与阅读管理改版

本轮按用户“自由发挥、直接修改、提供预览”授权实施。保留书架、添加、设置的原有导航，以及详情中的文案、阅读状态、总览和笔记顺序。

## 功能结果

| 请求 | 结果 |
|---|---|
| UI 技能 | 安装 frontend-design（anthropics/skills）与 ui-ux-pro-max（nextlevelbuilder/ui-ux-pro-max-skill），个人技能目录可用 |
| UI 层级 | 墨绿与纸白配色，标题、作者平台、状态、摘要分层，导航统一线性 SVG 图标 |
| 应用图标 | 保留“页间”，采用书页图形与汉字轮廓组成的矢量图标；网页及 Android 共用视觉 |
| 下拉框平铺 | 书架筛选改为单行可横滑文字标签，选中下划线；阅读状态、搜索平台与搜索方式平铺 |
| 刚开始看 / 状态颜色 | 新增“刚开始看”；七种状态分别着色，保留文字和选中标识；服务端 AI 输入契约同步 |
| 书架排序 | 最近记录、书名、字数、阅读状态；排序不重排持久化书籍数组 |
| 书架搜索高亮 | 书名、作者、总览、笔记匹配；命中旧笔记时展示对应片段；高亮先转义 HTML |
| 清空搜索 | 搜索框一键清空、再次聚焦选中旧词；从添加入口重新进入时重置上次搜索 |
| 字数 | 页头显示“24万（240,170）”；缺失或近似字数不伪造精确值 |
| 刷新资料 | 已关联原站 ID 的书支持刷新连载状态、字数、文案等书目字段；阅读状态、笔记、总览保留 |
| 密钥配置反馈 | 设置页显示配置状态；Android 保存后立即更新并提示；空输入不删除已存密钥，清除使用独立操作 |
| 长佩 | 接入官网公开书名搜索、详情导入与刷新；书籍详情可查看作者作品；作者名检索结果提供官网个人主页 |
| 截图导入 | 兼容图片解码、限制 OCR 工作尺寸、使用明确资源地址及压缩标志；增加长佩识别和可编辑字段；可以按确认的截图信息录入，无需搜索成功 |
| 番茄搜索 | 移除 Android 的硬编码拒绝并共用搜索响应校验；官网当前返回空响应/要求验证，在线关键词搜索仍未恢复；保留官网搜索、作品链接/ID及截图确认录入 |

## 关键文件

- `backend/public/preview/index.html`、`style.css`、`brand.svg`：界面与品牌。
- `backend/public/preview/app.js`、`archive-ui.js`：控件、状态、搜索、排序和刷新合并。
- `backend/public/preview/ocr.js`、`ocr-parser.js`：截图识别及确认录入。
- `backend/changpei.js`、`fanqie.js`、`server.js`：公开书目接口。
- `backend/overview.js`：接受新增的阅读状态。
- `mobile/runtime.js`、`build-web.cjs`：原生网络适配、密钥反馈与 OCR 资源构建。
- `mobile/android/app/src/main/res/drawable/ic_yejian.xml`：带应用名称的 Android 矢量图标。
- `backend/__tests__/redesign.test.js`：新增契约测试。

## 验证

- `node --test backend/__tests__/*.test.js`：21 项通过。
- 浏览器：排序、状态过滤与刷新后保存、搜索高亮、搜索重置、页头精确字数、配置状态通过。
- 长佩真实请求：搜索“入睡指南”，读取作品 8879，导入并刷新；确认原笔记、阅读状态、总览保留。
- 375px 手机、844px 横屏、768px 平板无横向溢出。
- 真实 Tesseract 引擎处理本地合成详情样张：正确提取番茄、作者、19位 ID、精确字数；书名存在一个 OCR 错字，需用户确认。
- 截图确认直接录入不调用平台接口，验证后移除测试记录。
- Android 页面包通过构建；使用浏览器中的原生桥接替身验证密钥保存/重进设置/空输入保留、真实长佩响应解码、未压缩本地 OCR 字库。
- Android 图标通过 `aapt2 compile` 资源编译。
- 预览截图为独立 localhost 端口下的示例数据，不修改手机书架数据。

## 限制与后续

- 番茄官网搜索本机实测触发验证，未绕过验证；搜索不可用不是“没有匹配作品”。
- OCR 为候选识别，不保证每个字准确；尚未拿到用户报错时的原始截图。
- 长佩作者名检索打开官方个人主页；作品详情中的作者作品列表展示官网当前页，不声称已获取全部作品。
- 密钥“已配置”只表示已保存，不代表密钥有效或账户有余额；本轮未调用真实付费 AI 请求。
- 未连接 Android 真机，未生成新版 APK；本轮交付为源码、构建通过的页面包和预览图。真机 WebView、文件选择器和分享面板仍需设备验证。
- 仓库在本轮开始前有未提交的 Android/预览实现。提交时单独保留相关已有代码基线，再提交本轮改动；不纳入无关的规格文档改动。

## 预览批注调整

- 书架筛选从两行色块改为单行横向滚动文字标签，保留状态颜色和 48px 点击高度；含留白高度从 140px 降至 64px。
- 375 / 390 / 768 / 844px 宽度下筛选高度均为 48px，页面无横向溢出；首尾状态过滤通过。详情页状态按钮不受影响。
